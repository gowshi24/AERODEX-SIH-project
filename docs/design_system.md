# AERODEX Design System & Visual Language

## Visual Aesthetic Principles
- **Clean & Spacious**: Light backgrounds with deep navy typography (`text-slate-900`, `bg-white`).
- **Blue/Cyan Accent System**: Primary `#2563eb`, Secondary `#06b6d4`, Emerald `#10b981`, Rose `#ef4444`, Amber `#f59e0b`.
- **Aviation Motifs**: Stylized airplane icon, route network lines, SVG India corridor map visualizer.
- **Card Elevation & Micro-animations**: Soft shadows (`shadow-xs`, `hover:shadow-md`), rounded cards (`rounded-2xl`, `rounded-3xl`), smooth hover states.
- **Typography**: Clean, readable sans-serif layout with font weights ranging from Medium to Black.
